Factory floor layouts A–O and tiled floors

Every layout puts 15 machines on the same 4 × 4 grid, with the same machine positions, jobs and random seeds. Two things change. The belt pattern (which side of each machine its input and output belts face) has five options, the columns below. The aisle topology has three options, the rows: one-way everywhere (A–E), two-way row aisles (F–J), or a two-way perimeter around one-way rows (K–O). Tiled floors then place copies of one layout side by side.

Results

Each family was first tested in its own sweep, so the tables use different settings. The last tab has all 15 layouts on the same footing. That is the RL training distribution (rnd_load), which is machine-bound, and there the layouts differ by no more than about 4%.

Tiled floors

Floors with more than 15 machines are built as tiles: complete copies of one 15-machine layout placed west to east with a 3-unit seam between them. Every tile has its own loop, input belt, output belt and parking lane. Because every tile's loop runs clockwise, the right vertical of one tile (southbound) runs next to the left vertical of the next tile (northbound), so the seam has no crossings.
