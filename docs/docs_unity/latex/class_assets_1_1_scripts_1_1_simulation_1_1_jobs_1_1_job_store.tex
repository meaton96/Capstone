\doxysubsection{Detailed Description}
Central repository for all active \doxylink{class_assets_1_1_scripts_1_1_simulation_1_1_jobs_1_1_job_data}{Job\+Data} instances in the simulation. 

Acts as a passive data store that translates static job definitions into live runtime trackers. The orchestrator queries and modifies these instances directly to manage the factory lifecycle.
