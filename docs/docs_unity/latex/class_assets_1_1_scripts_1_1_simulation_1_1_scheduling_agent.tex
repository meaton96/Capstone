\doxysubsection{Detailed Description}
ML-\/\+Agents Agent subclass that drives job-\/shop scheduling decisions. 

Listens for \doxylink{class_assets_1_1_scripts_1_1_simulation_1_1_types_1_1_decision_request}{Decision\+Request} events from the {\ttfamily \doxylink{class_assets_1_1_scripts_1_1_simulation_1_1_simulation_bridge}{Simulation\+Bridge}}, collects fixed-\/width observation vectors, and maps discrete action indices to dispatching rules.
