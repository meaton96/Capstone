\doxysubsection{Detailed Description}
Headless batch runner that drives the simulation through multiple configs × rules. 

Designed for data-\/collection builds. Reads a batch config JSON from the command line, then runs every (config, heuristic\+Rule) combination in series. Each episode\textquotesingle{}s results append to the existing CSV via Results\+Logger.
