\doxysubsection{Detailed Description}
Represents a physical processing unit within the factory simulation. 

Manages processing timers and state flags ({\ttfamily Finished\+Flag}, {\ttfamily Almost\+Done\+Flag}). This component is strictly passive; it does not initiate state transitions or communicate with the orchestrator. Instead, the {\ttfamily \doxylink{class_assets_1_1_scripts_1_1_simulation_1_1_simulation_bridge}{Simulation\+Bridge}} polls these flags to drive the factory lifecycle.
