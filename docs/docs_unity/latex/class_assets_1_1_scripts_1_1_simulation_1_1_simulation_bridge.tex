\doxysubsection{Detailed Description}
The central orchestrator responsible for driving the factory simulation. 

\doxylink{class_assets_1_1_scripts_1_1_simulation_1_1_simulation_bridge}{Simulation\+Bridge} implements a strictly centralized state machine. In a single {\ttfamily Update} tick, it harvests status flags from physical components (\doxylink{namespace_assets_1_1_scripts_1_1_simulation_1_1_machines}{Machines} and AGVs), manages job transitions, resolves \doxylink{namespace_assets_1_1_scripts_1_1_simulation_1_1_a_g_v}{AGV} assignments, and interfaces with the {\ttfamily \doxylink{class_assets_1_1_scripts_1_1_simulation_1_1_scheduling_agent}{Scheduling\+Agent}} to resolve scheduling conflicts. No other component is permitted to mutate {\ttfamily \doxylink{class_assets_1_1_scripts_1_1_simulation_1_1_jobs_1_1_job_data}{Job\+Data}} state.
