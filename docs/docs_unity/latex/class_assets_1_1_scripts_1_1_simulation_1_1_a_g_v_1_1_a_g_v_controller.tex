\doxysubsection{Detailed Description}
Controls navigation and physical movement of a single Automated Guided Vehicle (\doxylink{namespace_assets_1_1_scripts_1_1_simulation_1_1_a_g_v}{AGV}). 

Acts as a state-\/driven controller that interfaces with the {\ttfamily Nav\+Mesh\+Agent} and {\ttfamily \doxylink{class_assets_1_1_scripts_1_1_simulation_1_1_factory_layout_1_1_traffic_zone_manager}{Traffic\+Zone\+Manager}}. This class follows an "{}orchestrator-\/flag"{} pattern:\+ it manages physical movement and sets status flags ({\ttfamily Picked\+Up\+Flag}, {\ttfamily Delivered\+Flag}) for a central supervisor to process, rather than triggering job state transitions directly.
