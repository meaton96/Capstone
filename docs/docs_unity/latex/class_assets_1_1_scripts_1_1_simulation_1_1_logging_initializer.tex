\doxysubsection{Detailed Description}
Orchestrates the initialization of static logging utilities. 

Ensures that both {\ttfamily Results\+Logger} and {\ttfamily Sim\+Logger} are configured with appropriate directory paths and verbosity levels. It handles cross-\/platform directory resolution to ensure logs are written to persistent storage locations outside of read-\/only application bundles.
