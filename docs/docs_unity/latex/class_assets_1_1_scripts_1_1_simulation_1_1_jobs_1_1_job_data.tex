\doxysubsection{Detailed Description}
Encapsulates all persistent data, state, and tracking metrics for a single job. 

This is a pure data container. Logic for state transitions, \doxylink{namespace_assets_1_1_scripts_1_1_simulation_1_1_a_g_v}{AGV} assignments, and routing is handled exclusively by the central orchestrator. It maintains the operation sequence, machine eligibility, and timing stats for reward calculation.
