Detailed Description

Encapsulates all persistent data, state, and tracking metrics for a single job.

This is a pure data container. Logic for state transitions, AGV assignments, and routing is handled exclusively by the central orchestrator. It maintains the operation sequence, machine eligibility, and timing stats for reward calculation.
