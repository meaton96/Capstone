Detailed Description

Utility class for generating Flexible Job Shop Scheduling Problem (FJSSP) instances.

Provides methods to generate a series of jobs with randomized arrival times, operation sequences, and machine eligibility based on configured probability distributions.

An array of FJSSPJobDefinition objects sorted by ArrivalTime.

For each operation in a job's sequence, this method assigns independent processing times for every eligible machine instance. This creates the "flexible" aspect of the FJSSP, providing signals for the router to exploit.
