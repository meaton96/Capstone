Detailed Description

The central orchestrator responsible for driving the factory simulation.

SimulationBridge implements a strictly centralized state machine. In a single Update tick, it harvests status flags from physical components (Machines and AGVs), manages job transitions, resolves AGV assignments, and interfaces with the SchedulingAgent to resolve scheduling conflicts. No other component is permitted to mutate JobData state.
