Detailed Description

Controls navigation and physical movement of a single Automated Guided Vehicle (AGV).

Acts as a state-driven controller that interfaces with the NavMeshAgent and TrafficZoneManager. This class follows an "orchestrator-flag" pattern: it manages physical movement and sets status flags (PickedUpFlag, DeliveredFlag) for a central supervisor to process, rather than triggering job state transitions directly.
