Detailed Description

Manages the lifecycle and retrieval of the AGV fleet.

Serves as a centralized container and factory. The SimulationBridge orchestrator queries this pool to identify and dispatch available units based on their current operational state.

Identifies the best candidate for a new task dispatch.

Performs a two-pass search: first for units already at their parking stations (Idle), and second for units currently ReturningToParking that can be redirected mid-route to optimize travel time.
