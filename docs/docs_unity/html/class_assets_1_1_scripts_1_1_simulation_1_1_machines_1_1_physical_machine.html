Detailed Description

Represents a physical processing unit within the factory simulation.

Manages processing timers and state flags (FinishedFlag, AlmostDoneFlag). This component is strictly passive; it does not initiate state transitions or communicate with the orchestrator. Instead, the SimulationBridge polls these flags to drive the factory lifecycle.
